# ERP OUTPUT.3A — Structured Template Studio Prototype — Implementation Report

**Phase:** OUTPUT.3A (Work Package 6 of the Global Output Framework master program, v6.1)
**Date:** 2026-07-26
**Status:** COMPLETE — demo gate PASSED

---

## 1. Objective

Prove the structured Template Studio UX and its security boundary using safe fixtures:
a feature-flagged admin prototype on the installed TipTap foundation, driving the
**same canonical Executive Ledger HTML builder used by official issuance** — with no
Puck rebuild, no free-pixel positioning, no protected asset bytes in the browser,
and no script/style injection.

---

## 2. What Was Built

### 2.1 Structured body schema (`src/lib/template-studio/schema.ts`)

- `StudioBodySchema` v1 (zod-validated), stored in `erp_report_templates.body_schema_json`
  (+ `studio_schema_version`) — columns created in OUTPUT.1.
- Governed block set: `heading` (H1–H3, approved alignments), `paragraph` (TipTap rich),
  `clause` (auto-numbered, TipTap rich), `key_value` (≤40 rows), `table` (≤8 cols, ≤100 rows,
  optional `repeatBinding` for repeating datasets), `divider`, `spacer` (4–48 pt clamp),
  `columns` (equal / left-wide / right-wide only).
- Body cap: 120 blocks. Unknown block kinds are rejected by the discriminated union.

### 2.2 Save-time validation and sanitization (`src/lib/template-studio/validate.ts`)

- ProseMirror allowlist walk: only `doc, paragraph, text, hardBreak, bulletList,
  orderedList, listItem, bindingToken` nodes and `bold, italic, underline, textStyle`
  marks. Unknown nodes/marks/attributes are **hard save-time rejections**.
- Style clamps: font size 8–36, safe 6-digit hex colors, approved alignments only.
- Variable governance: every `{{token}}` and binding chip must exist in
  `ERP_BINDING_REGISTRY`, and — when an output scope is selected — in the per-output
  Studio allowlist (`src/lib/template-studio/allowlists.ts`).

### 2.3 Canonical mapping (`src/lib/template-studio/schema-to-el.ts`)

- Pure mapper: Studio schema → `ExecutiveLedgerDocument` sections (body/richHtml,
  key_value, table, divider, column). Rich text renders through the existing hardened
  `renderProseMirrorDocToHtml` (binding substitution + escaping).
- Unresolved tokens stay visible (no fabrication); heading/label text is HTML-escaped.
- Frame, header, footer, margins, signatory, stamp, and QR remain governed by the
  Executive Ledger renderer — **outside** the editable body, per v6.1.

### 2.4 Server actions (`src/server/actions/output/template-studio.ts`)

- `listStudioTemplates`, `loadStudioTemplate`, `saveStudioDraftBody`, `previewStudioBody`.
- All guarded by `OUTPUT_TEMPLATE_STUDIO_ENABLED` + `reports.manage`.
- **Governance boundary:** saves are refused unless `governance_status` ∈ {draft, rejected} —
  a Studio edit can never affect an approved/published template.
- Save is blocked on any validation error; preview still renders (so admins can SEE
  the problem) but surfaces the errors as warnings.
- Preview uses synthetic EN/AR fixtures (`fixtures.ts`) and passes **no branding
  context** — stamps/signatures/QR appear only as protected placeholders; real assets
  exist only in the server-side issuance path.
- Audit: `studio_save_draft_body` with block count + variable list.

### 2.5 Feature-flagged admin UI

- `src/app/(protected)/admin/reports/template-studio/page.tsx` — permission +
  flag gate (`FlaskConical` "Not Enabled" card when flag is off).
- `src/features/template-studio/template-studio-page-client.tsx` — workbench:
  template picker (governance state visible), block-list editor with add/reorder/remove,
  LTR/RTL toggle, per-output allowlist scope selector, debounced live A4 preview
  (sandboxed iframe, canonical EL HTML), EN/AR fixture toggle, validation warnings
  panel, save-blocked error panel, localStorage draft autosave + restore/discard bar.
- `src/features/template-studio/studio-block-editor.tsx` — per-block editors;
  paragraph/clause/columns reuse `ReportDesignerRichTextEditor` (TipTap + binding chips).
- Route registered in `route-access-registry.ts` (`reports.manage`) and
  `workspace-route-registry.ts` (singleton tab "Template Studio").
