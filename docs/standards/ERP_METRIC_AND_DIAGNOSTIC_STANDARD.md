# Metrics, advisory AI and diagnostics

Applies to existing and new ERP modules. Preserve the administrator scope standard, ordinary-caller RLS, workspace lifetime and compact embedded lists.

- Every metric names its source, meaning, date basis, completeness and read time. Current backlog is different from events within a period. Totals use verified counts or complete bounded pages. A budget, malformed result, denied query or dependency failure is unavailable, never zero.
- Independent sections keep their own outcomes. Failed sections must not display stale values or an empty-success message. A successful refresh clears the old error. Changing filters/accounts retires previous results and pending work. Do not use a shared elevated cache for private metrics.
- Previews identify their limit. Exports and delivery must use the existing complete authorized traversal, never the displayed preview. Unknown token/cost evidence remains unknown. Recorded cost estimates are not provider invoices; currency must be evidenced before summing monetary values.
- The AI dashboard's selected day uses Dubai time. Seven/thirty-day selections are rolling windows. Definitions live beside the collectors. AI suggestions are advisory; source availability, current permissions and flags are rechecked. Changed facts invalidate pending output. Readiness, salary and approvals remain deterministic authorized workflows.
- Use the canonical usage schema: feature_area, operation_type, model_id, input_token_count, output_token_count and subject metadata. Do not revive obsolete HR columns. Metadata-only context must not claim that file contents were reviewed. Missing evidence never certifies compliance or fitness.
- Diagnostics use the bounded allowlisted reporter. Emit a support reference, known route template, source/build identity and event sequence/category. Never emit request headers, raw URLs, record identifiers, tokens, prompts, OCR, recipients or provider payloads. Cancellation is distinct from an application fault. Logging failure must not replay a business operation.
- Review indexes using keys, predicates, uniqueness, access method, operator classes and measured workload. Keep structural candidates separate from proven regressions; do not remove an index solely because two names mention the same column.
- Run `node tooling/performance/f17-adoption-audit.mjs` from the candidate to inventory routes, actions, forms, lists and explicit navigation. Its optional historical inventory and output arguments are local evidence paths. Static coverage is not runtime/manual acceptance.
- Browser/computer-control work requires a new explicit owner instruction. Software, native database and in-memory measurements are labelled accordingly; they do not certify real-device behavior or production capacity.
