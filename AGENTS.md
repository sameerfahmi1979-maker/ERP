## Administrator and module authorization

Read `docs/standards/ERP_ADMINISTRATOR_SCOPE_STANDARD.md` when adding modules or changing authorization. Preserve separate company/branch assignments per user, exact scope checks, protected inherited permissions, ordinary-role grants and independent approvals. Global System is an administrative scope, never a company. No browser testing or computer control without a specific explicit owner instruction.
